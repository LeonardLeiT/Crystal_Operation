# σ foam设计约束

- 空间群：`P4₂/mnm`；四方比例：`c/a=131/253`。
- 五类站点：Z12–2b、Z12–8i、Z14–8i、Z14–8j、Z15–4f。
- 周期Voronoi配位已经验证为`10×12 + 16×14 + 4×15`。
- 五类Laguerre权重使每个胞元体积等于四方盒体积的`1/30`。
- 15个孪晶面对构成完美匹配，全部来自真实周期Voronoi公共面。
- 两晶粒在公共面中心共享FCC晶格点；Σ3采用`60°/<111>`。
- 完整胞元不裁切、不预先wrap；只删除小于半个FCC最近邻距离的周期重叠。
- 固定`size=8.6`并保持约7–8万原子，不研究尺寸效应。
