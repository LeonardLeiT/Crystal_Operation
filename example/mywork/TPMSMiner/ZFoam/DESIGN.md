# Z foam 设计约束

1. 使用 `hP7-Zr4Al3, P6/mmm` 的精确 Wyckoff 点集；`c/a=5.390/5.433`，
   `2e` 内部参数为 `z=1/4`。
2. 周期 Voronoi 邻接必须给出 `[12,12,12,15,15,14,14]`，否则拒绝构造。
3. 使用求解得到的三类 Laguerre 权重，使 7 个胞元体积严格相等。
4. Z12、Z14、Z15 各选择一个真实同类公共面，构成 3 对候选 CSL；第三个
   Z12 保持普通晶界取向，不为了凑偶数而复制原胞。
5. Σ3 使用 FCC `60°/<111>`；负对照 Σ5 使用 `36.869897°/<100>`。每对共享
   公共面中点的晶格锚点，保证取向关系和晶格平移相位同时受控。
6. 固定约 7–8 万原子的尺寸，只删除距离小于 `0.5 × FCC最近邻距` 的周期重叠。

该结构的研究价值在于其三角柱式六方基本单元能与 A15 的方形基本单元兼容，
可进一步用于 Z/A15 拼接、Z/C15 层错及十二重近似结构搜索。
