# C15-Laves 孪晶前驱体设计

## 与 W-P 的本质区别

- W-P 使用 A15 点集，每个立方周期胞有 8 个胞元：2 个 Z12 和 6 个 Z14。
- 本构型使用 C15 点集，每个立方周期胞有 24 个胞元：8 个 Z16 和 16 个 Z12。
- C15 的胞元中心、Voronoi 面、邻接图及晶粒数量均不继承 W-P。

## 第一版约束

0. 固定使用 `size=9.25`；Cu晶格常数3.61 Å时完整构型约7–8万原子，不做
   尺寸效应或尺寸序列筛选。
1. 使用精确 C15 `8a/16d` 分数坐标，并验证周期配位数为 `8×16 + 16×12`。
   默认对 Z16 使用约 `-0.009748098845` 的无量纲 Laguerre 权重，使两类
   胞元体积都严格为周期盒的 `1/24`；原始 Voronoi 可作为非等体积对照。
2. 只允许同类胞元在真实最近邻 Voronoi 面上组成孪晶对。
3. 先求面法向最均衡的完美匹配，再按“同一胞元类型、同一无向法向只保留
   一个空间层”去重。Z16 保留四种 `<111>`；Z12 保留六种 `<110>`，不再让
   `[0,1,1]` 和 `[0,1,-1]` 各出现相隔半周期的第二层。
4. 将 FCC `[111]` 转到公共面法向，第二个晶粒绕该法向旋转 `±60°`。
5. 两个晶粒在公共面中点共享一个 FCC 晶格点，防止只有取向关系而没有共格
   平移相位。
6. 被第二层规则排除的4个Z12晶粒使用固定随机种子的独立普通取向，不共享
   孪晶锚点；相对其余所有晶粒的立方消取向避开Σ3/Σ5标称角至少1°。这些
   普通取向在所有Σ3/Σ5及swap对照中保持相同。
7. 构造每个完整周期 Voronoi 胞元，不裁切、不预先 wrap；最后仅删除小于
   `0.5 × FCC最近邻距离` 的周期重叠原子。

## 当前限制

当前10个指定 Σ3 面采用单层规则，20个晶粒属于孪晶对，4个晶粒保持普通取向。
它们在空间方向上是三维分布的，但尚未形成预先连通的 Σ3 面网。因此该构型适合作为 C15 新胞形
的首轮退火筛选，不应在退火前就称为新的 TPMS。后续版本需要在 C15 面邻接图
上联合求解多边 Σ3 取向约束，并以三个周期方向都贯通作为硬约束。
