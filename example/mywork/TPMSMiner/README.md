# TPMSMiner

当前实验目录包含四个独立的Frank–Kasper前驱体：

- [C15-Laves](C15/README.md)：立方，`8×Z16 + 16×Z12`；
- [σ foam](Sigma/README.md)：四方，`10×Z12 + 16×Z14 + 4×Z15`。
- [SigmaZ2](SigmaZ2/README.md)：σ 相沿 Z 双周期，60-cell 独立孪晶库；8 套 Σ3 设计加同面 Σ5 对照，且不复用 Sigma 的配对。
- [Z foam](ZFoam/README.md)：六方 FK Z phase / HS-I dual，`3×Z12 + 2×Z14 + 2×Z15`。
