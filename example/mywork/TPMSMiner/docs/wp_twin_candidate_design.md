# W-P 孪晶组合候选设计

## 约束边界

候选只改变三对 Tet 的局部晶体学组合，不改变已经验证的几何基础：

- A15 的两个 Dod 和三对 Tet 位点；
- 等体积 Laguerre 胞元；
- 完整胞元生成，不裁剪或预先 wrap；
- 每对 Tet 共用一个 CTB 平面晶格锚点；
- Dod0 `(0,0,0)` 和 Dod1 `(0.5,0.5,0.5)` 不属于任何 Tet 孪晶对，
  因而使用固定种子生成的两个独立随机取向，并保持各自的晶格锚点；
- 随机 Dod 取向对彼此及全部 Tet 的立方消取向角都避开 Σ3/Σ5
  标称角至少 3°，防止偶然产生近 CSL 关系；
- 论文 Table 1 的 Σ3 或 Σ5 取向；
- 周期最小镜像重叠清理。

因此，候选中的局部取向差和原子相位是受约束的。尚未验证的是不同方向
锚点组合在退火后产生的全局晶界拓扑。

## 第一批优先级

1. `wp_s3_s3_s3_reference`：文章正对照，锚点秩为3。
2. `open_x/open_y/open_z`：保留两个正交 Σ3 通道，将第三个方向替换为
   Σ5。这是最值得测试的新组合，因为它只释放一个方向，同时仍保留二维
   互锁骨架。
3. `swap_x/swap_y/swap_z`：保持三个 Σ3 通道，但交换一对 Tet 的 T1/T2
   位置，用于改变 Dod0/Dod1 周围非对称普通晶界的分布。
4. `anchor_x/anchor_y/anchor_z`：仅保留一个 Σ3 通道，属于第二优先级。
5. `wp_s5_s5_s5_negative`：文章负对照。

三个 `open_*` 必须成组运行。理想情况下它们应表现为旋转等价；如果结果
差异显著，应优先检查盒可公度性、数值误差和退火流程，而不是立即解释为
材料效应。

## 判据

初始构型只检查：

- 8个晶粒全部非空；
- 每一对 Tet 的立方对称约化取向差分别为 Σ3 的60°或 Σ5 的36.8699°；
- 共享 CTB 锚点保持一致；
- 重叠清理后的最小距离不低于设定阈值；
- Σ3 候选应在 CNA 中出现 HCP 原子，纯 Σ5 负对照不应出现。

是否形成 TPMS 必须由后续 LAMMPS 退火、晶界网格提取和拓扑分析判断。
