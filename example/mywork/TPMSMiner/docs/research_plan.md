# TPMSMiner 研究路线

## 1. 研究假设

已有 Diamond-surface 结果提示，高稳定性可能不只来自“孪晶界是 TPMS”，
而来自以下因素的组合：

- TPMS 的零或较低平均曲率减小各向同性毛细驱动力；
- 两个 labyrinth 体积分数平衡，且在周期盒内保持双连续；
- 晶体取向与模拟盒严格可公度，不在边界引入额外错配；
- 局部界面法向接近该取向差下的低能晶界面；
- 曲面拓扑约束晶界整体平移，并允许弛豫后形成稳定的微观分面。

需要特别检验：固定的两套晶体取向只有固定的相干孪晶面。TPMS 法向随位置
连续变化，因此原子尺度界面可能是相干面、非相干面、台阶和位错网络的组合，
而不是处处相干的光滑孪晶界。

## 2. 搜索变量

### 2.1 几何变量

- surface family 和空间群；
- Fourier/nodal 方程系数；
- level-set 偏移量与两相体积分数；
- 单胞尺寸、重复数和允许的超胞扩大量；
- 表面积、Euler characteristic、genus、颈部尺寸；
- 平均曲率误差与 Gaussian curvature 分布。

### 2.2 晶体学变量

- 晶格类型和元素；
- 晶粒 1 取向；
- 与公共周期超胞兼容的晶粒 2 取向；
- 考虑晶体对称性后的最小错配角；
- CSL/DSC 指标以及公共超胞原子数；
- 局部界面法向相对于低能晶界面的偏差。

这里的 DSC 若表示 displacement-shift-complete lattice，需要与当前项目中的
Diamond Schwarz Crystal 缩写分开记录，避免概念混淆。

## 3. 分级筛选流程

### Stage A：连续几何筛选

在不生成原子的情况下计算：

- 周期性残差；
- 两相体积分数；
- 表面积/体积；
- 曲率分布；
- 连通分量和拓扑是否符合预期；
- 最窄通道是否足以容纳目标晶格。

这一阶段用于快速淘汰断连、颈部过窄或数值曲率误差过大的候选。

### Stage B：晶体学可公度搜索

1. 从整数晶向或整数四元数生成晶粒 1 的可公度取向；
2. 建立最小公共周期超胞；
3. 在同一超胞下搜索晶粒 2；
4. 用 FCC/BCC 等点群约化错配角；
5. 约束最小错配角，避免两个晶粒实际属于同一等价取向；
6. 限制超胞膨胀率和总原子数。

推荐先扫描 `15°、30°、45°` 三档最小错配角，而不是只采用一个阈值。

### Stage C：低成本原子筛选

- 删除过近原子并记录删除比例；
- 计算未弛豫界面附近的配位数和局部应变；
- 使用短程能量最小化；
- 比较单位界面面积的超额能；
- 检查晶粒核心取向是否保持。

### Stage D：稳定性验证

- 0 K 共轭梯度最小化；
- 多温度退火和冷却；
- NVT 与 NPT 对照；
- 多个尺寸进行有限尺寸收敛；
- 多个随机取向和随机速度种子；
- 长时间晶界迁移与晶粒旋转测试。

## 4. 评价指标

每个候选至少保存：

- `periodicity_residual`：两个晶粒分别沿三个盒矢量的匹配误差；
- `disorientation_angle`：考虑点群后的最小取向差；
- `excess_energy_per_area`；
- `interface_area` 和 `area_change_after_relaxation`；
- `grain_volume_fraction`；
- `grain_survival_fraction`；
- `orientation_drift`；
- `topology_preserved`：连通性和 genus 是否保持；
- `interface_distance_rms`：弛豫前后界面位移；
- CNA/PTM 晶体原子比例和缺陷原子比例。

不能只用总势能排名，因为不同 TPMS 的界面面积、原子数和体积分数不同。

## 5. 可形成论文主线的方向

### 方向 A：TPMS 几何—稳定性图谱

在相同材料、盒尺寸、体积分数、取向差和近似界面面积下，对 D、P、G、I-WP、
Neovius 等结构做系统对照，建立曲率、拓扑与热稳定性的关联。

### 方向 B：晶界能加权的 TPMS 逆设计

不是寻找几何上最漂亮的 TPMS，而是最小化

`E_proxy = integral_surface gamma(n, delta_g) dA`。

其中 `gamma` 是取向差 `delta_g` 下随界面法向变化的晶界能。可以调整 Fourier
系数，使法向分布更多落在低能晶界方向附近。

### 方向 C：弛豫后的自发分面化

比较不同光滑 TPMS 在原子弛豫后是否形成可重复的台阶—分面网络，并研究该网络
是否仍保持原始 TPMS 的拓扑。这可能比宣称“原子晶界严格等于数学 TPMS”更准确，
也更有物理内容。

### 方向 D：多晶粒和多 level-set 网络

使用多个相位平移的 level set 构造三晶粒或四晶粒周期网络，研究无传统三叉结、
或具有受控三叉结的拓扑。该方向应放在双晶模型验证完成之后。

## 6. 对照实验要求

为了把几何效应与其他因素分开，跨 TPMS 比较时应尽量固定：

- 元素、势函数和晶格常数；
- 实际盒体积和原子数范围；
- 两个晶粒的体积分数；
- 考虑点群后的错配角；
- 界面面积或单位体积界面面积；
- 最小特征尺寸；
- 最小化、退火和统计流程。

Diamond-surface 应始终作为正对照；平面晶界、随机 Voronoi 双晶以及相同面积但
非极小曲面的 level set 可作为负对照。

## 7. 建议的第一轮最小研究集

第一轮不要同时铺开所有曲面。建议只比较：

1. Schwarz D：已有基准；
2. Schwarz P：当前正在实现的双晶周期模型；
3. Gyroid：拓扑和手性明显不同；
4. 平面周期双晶：基础对照。

每类选择 3 个尺寸、3 档错配角和至少 5 个可公度取向种子。确认评价流程能够
区分稳定与不稳定结构后，再加入 I-WP、Neovius 和 Fourier 逆设计。

## 8. 下一步需要共同决定

1. 研究材料和势函数：先固定 Cu，还是直接使用论文中的体系？
2. “稳定”的主判据：界面不迁移、拓扑不改变、能量低，还是力学性能保持？
3. 是否允许模拟盒相对目标尺寸小幅扩张以获得严格周期取向？
4. 第一阶段使用 nodal approximation，还是从数值极小曲面网格开始？
5. LAMMPS 工作流由 Python 直接生成输入文件，还是只生成 data 并调用已有模板？
